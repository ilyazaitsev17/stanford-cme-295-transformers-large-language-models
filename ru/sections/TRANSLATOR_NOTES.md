# Заметки переводчика — сводный документ

**Рабочий материал. Не для публикации.** Здесь собраны все заметки переводчика из 4 файлов разделов. Финальный документ `cheatsheet_ru_full.md` этих заметок не содержит.

Дата сборки: 2026-05-13 (Этап 6.5). Все «сомнения для валидации» на момент сборки — решены и зафиксированы заказчиком.

# Раздел 1. Основы (`01_foundations.md`)

## Использованные термины
- **token → токен** — стандартный вариант, без альтернатив.
- **tokenizer → токенизатор** — единственный устоявшийся русский вариант.
- **subword → подслово** — ЗАФИКСИРОВАНО заказчиком на Этапе 6 (изначально в черновике стоял «сабворд», заменено на «подслово» как более академичный вариант — это документ Stanford). При первом упоминании дан «(subword)».
- **embedding → эмбеддинг** — стандарт в индустрии (Sber, Yandex, OTUS), хотя в академии встречается «вложение». Выбрано «эмбеддинг» как более узнаваемое для целевой аудитории канала.
- **cosine similarity → косинусная схожесть** — допустим также «косинусное сходство»; оба варианта живые. Взял «схожесть» — короче и чаще в проф. речи.
- **BPE / Unigram** — оставлены латиницей, как имена собственные алгоритмов.
- **ANN / LSH** — оставлены аббревиатуры с раскрытием на русском при первом упоминании.

## Места с осознанной правкой смысла
1. **«patterns hard to interpret because too low-level»** → «паттерны труднее интерпретировать из-за слишком низкого уровня». Английский оборот более лаконичный, в русском раскрыл явно.
2. **«arbitrary level of granularity»** → «произвольный уровень детализации». «Granularity» формально переводится как «гранулярность», но «детализация» естественнее в русском техническом тексте.
3. **«ensure consistent input sequence lengths»** → «дополнения коротких последовательностей до одинаковой длины». Переформулировал как описание механизма паддинга, потому что в одном предложении сразу даётся и определение `[PAD]`, и его функция.
4. **«The angle θ characterizes the similarity»** → добавил фразу-«мостик»: «чем меньше угол, тем более похожи объекты». В оригинале это подразумевается схемой с тремя картинками плюшевого медведя.
5. **«ANN and LSH are methods that approximate the similarity operation efficiently»** → объединил с раскрытием аббревиатур, потому что русский читатель видит ANN/LSH впервые.

## Решённые сомнения
- **Иллюстрация плюшевых медведей** (Similar / Dissimilar / Independent) — в MD заменена таблицей с описанием. Для финального PDF нужна сама схема.
- **Иллюстрации к таблице токенизаторов** — оставлены в таблице как однострочные примеры через бэктики. В PDF оформлены богаче.
- **«[UNK]» / «[PAD]»** — оставлены латиницей, как в оригинале. Стандарт, не локализуются.

# Раздел 2. Трансформеры (`02_transformers.md`)

## Использованные термины
- **self-attention** — оставлен EN, как зафиксировано. Везде по тексту единообразно.
- **encoder / decoder → энкодер / декодер** — зафиксировано.
- **embedding → эмбеддинг** — зафиксировано.
- **multi-head attention → многоголовое внимание (MHA)** — по глоссарию; аббревиатура MHA раскрыта при первом упоминании.
- **GQA / MQA** — раскрыты при первом упоминании, далее аббревиатуры.
- **cross-attention → кросс-внимание**, **masked self-attention → маскированный self-attention** — по глоссарию.
- **FFNN → полносвязные нейросети прямого распространения** — раскрытие при первом упоминании.
- **RoPE → вращательные позиционные эмбеддинги** — по глоссарию.
- **sparse / low-rank → разреженность / низкий ранг** — по глоссарию.
- **Flash Attention** — имя собственное метода, оставлено EN без перевода.
- Названия моделей (BERT, GPT, LLaMA, Mistral, Gemma, DeepSeek, T5) — EN без изменений.

## Места с осознанной правкой смысла
1. **Блок «Компоненты» / диаграмма с FFNN, Self-Attention, Cross-Attention, Masked Self-Attention.** В оригинале PDF это визуальная схема-«стопка» из блоков. Добавлен связующий абзац («Декодер дополнительно содержит слой кросс-внимания…»), потому что без схемы голая таблица «энкодер/декодер» не объясняет, откуда берутся cross-attention и masked self-attention. **УТВЕРЖДЕНО** заказчиком — оставить как есть. В финальном PDF, если схема воспроизведена, абзац можно сократить.
2. **«landmark model»** → «знаковая модель». Альтернативы: «эпохальная», «революционная».
3. **«across multiple heads»** → «параллельно по нескольким "головам"». Добавил «параллельно» — в оригинале подразумевается.
4. **«takes some text as input, and outputs meaningful embeddings»** → разбил на два оборота. Чистая стилистика.
5. **«treats all problems as text-to-text problems»** → «трактует любую задачу как задачу преобразования текста в текст».
6. **«heads» (attention heads)** → «головы внимания», в кавычках при первом неформальном упоминании. Устоявшийся русский термин (ШАД, Хабр).

## Решённые сомнения
- **Расширенный абзац в «Компонентах»** — УТВЕРЖДЕНО, оставлено как есть.
- **«знаковая модель»** для «landmark model» — принято.

# Раздел 3. Большие языковые модели (`03_llms.md`)

## Использованные термины
- **fine-tuning → дообучение** — зафиксировано; при первом упоминании дан «(fine-tuning)».
- **quantization → квантизация** — зафиксировано. Производное «квантизованный» (QLoRA) — от него же.
- **embedding → эмбеддинг** — зафиксировано.
- **LLM, NLP, SFT, PEFT, LoRA, RM, BoN, RL, RLHF, PPO, DPO, MoE, CoT, ToT, QLoRA** — все раскрыты при первом упоминании, далее аббревиатуры.
- **preference tuning → настройка по предпочтениям**, **prompting → промптинг**, **decoding sampling → сэмплирование при декодировании**, **reward model → модель вознаграждения**, **mixture of experts → смесь экспертов**, **distillation → дистилляция**, **gate → гейт** — по глоссарию.
- **prefix tuning** — оставлен EN с русским пояснением в скобках («prefix tuning (настройка префикса)»).
- **reward hacking → «взлом вознаграждения» (reward hacking)** — по глоссарию, с EN при первом упоминании.
- **soft labels → «мягкие» метки** — по глоссарию.
- **alignment → выравнивание** — ЗАФИКСИРОВАНО заказчиком (системный термин).
- **post-training → пост-обучение** — ЗАФИКСИРОВАНО заказчиком.
- Названия (LLaMA) — EN без изменений.

## Места с осознанной правкой смысла
1. **Формула LoRA.** В оригинале PDF факторизация показана визуально (прямоугольники). В тексте дана формула `W ≈ W₀ + B×A` и **отдельной строкой явно прописаны размерности** ($B \in \mathbb{R}^{d\times r}$ и т. д.) и условие $r \ll d, k$. В оригинальном тексте размерности словами не названы. **УТВЕРЖДЕНО** заказчиком — оставить.
2. **«post-training approaches»** → «подходы этапа пост-обучения». Русская калька «пост-обучение» встречается в русскоязычных материалах.
3. **«aligning the model» / «aligns the behavior»** → «выровнять модель» / «выравнивает поведение».
4. **«Demote bad answers»** (подпись в диаграмме lifecycle) → «Понижение приоритета плохих ответов». Дословно «demote» = «понизить в ранге»; смысловой перевод точнее.
5. **«supervised approaches»** → «обучаемые "с учителем" подходы». Классический ML-термин.
6. **«incentivizes higher rewards»** → «поощряет более высокие вознаграждения». Стилистика.
7. **argmax-формула BoN** — в оригинале индекс записан как $i \in [\![1, N]\!]$ (двойные скобки = целочисленный интервал). Упрощено до $i \in [1, N]$ для читаемости в Markdown; в финальном LaTeX вернуть `\llbracket ... \rrbracket`.

## Решённые сомнения
- **«alignment» → «выравнивание»** — зафиксировано заказчиком (системный термин, единообразно по всему тексту).
- **«post-training» → «пост-обучение»** — зафиксировано заказчиком.
- **Явное добавление размерностей в формулу LoRA** — УТВЕРЖДЕНО, оставлено как есть.

Сохранена табличная структура, колонка «Иллюстрация» заменена кратким текстовым описанием графика. **УТВЕРЖДЕНО** (временно). В финальном PDF — вернуть графики.
6. **«autonomously pursues goals»** → «автономно преследует цели». Нейтрально и точно.
